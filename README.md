# Опрос предпочтений врачей в отношении медицинских ИИ-решений

РЭУ им. Г.В. Плеханова. Flask + SQLite в одном контейнере.
Поток: согласие → анкета → инструкция → пример таблицы → задания парного выбора
(10 + 2 повтора) → заключительные вопросы → благодарность.

| файл | назначение |
|---|---|
| `app.py` | маршруты и логика прохождения |
| `db.py`, `schema.sql` | соединение с БД и структура таблиц |
| `design/attributes.json` | характеристики ИИ-решений и их уровни |
| `design/questions.json` | вопросы анкеты, включая правила пропуска; `"after_tasks": true` — вопрос после заданий |
| `design/generator.py` | сборка пар профилей (сейчас заглушка) |

## Запуск

```sh
docker compose up --build
```

Локально: http://localhost:8000/survey/. На сервере: https://aitech.rea.ru/survey/.

Настройки — в `docker-compose.yml`, в секции `environment`.
Код монтируется с диска, поэтому после `git pull` сервер подхватывает
правки сам; пересборка нужна только при изменении `requirements.txt`.

**Важно:** правки в `environment` (например, `N_TASKS`) так не подхватываются —
переменные окружения задаются при создании контейнера. После их изменения:

```sh
docker compose up -d
```

Compose увидит изменившуюся конфигурацию и пересоздаст контейнер. База при
этом сохраняется: она лежит в `data/` на диске.

HTTPS не настраивается: этим занимается хостер. Приложение слушает
обычный HTTP-порт, TLS терминируется перед ним.

## Данные

Повторы: после `N_TASKS` уникальных ситуаций показываются ещё `N_REPEATS`
уже виденных, с переставленными колонками (в таблице `task` поле `repeat_of`).

Панель исследователя: https://aitech.rea.ru/survey/results — вход по ключу
из `.env` (`RESULTS_KEY`, без него страница отдаёт 404). Там сводка
(воронка, ответы по дням, распределения анкеты, выборы, повторы), таблица
респондентов с пометками качества и удалением, выгрузка CSV и очистка базы
(перед очисткой копия сохраняется в `data/backups/`). Код — `admin.py`.

В CSV строка на ситуацию выбора. Номера `task` с единицы; `repeat_consistent`
= 1, если в повторе выбран тот же профиль; `choice_position` — колонка на
экране (1/2/none).

База — `data/survey.sqlite3`. Копировать файл на работающем сервере нельзя:
при включённом WAL получится битый снимок. Правильно так:

```sh
docker compose exec web python -c "import sqlite3; s=sqlite3.connect('/data/survey.sqlite3'); d=sqlite3.connect('/data/backup.sqlite3'); s.backup(d); d.close()"
```

Готовый файл появится рядом: `data/backup.sqlite3`.

## Что стоит сделать перед сбором данных

- `design/generator.py` — заглушка со случайными парами. Для оценки
  коэффициентов нужен нормальный план эксперимента.
- В анкете 6 вопросов, а текст согласия обещает ещё блок про отношение
  к медицинским технологиям и ~15 минут.
- Нет проверочного задания на внимательность и нет кнопки отказа,
  хотя согласие обещает право прекратить участие.
