# Опрос студентов: драйверы и барьеры использования российских ЛЛМ

РЭУ им. Г.В. Плеханова. Отдельный контейнер рядом с опросом врачей
(тот же движок: Flask + SQLite).

Поток: согласие → анкета (9 вопросов, часть пропускается для
не пользующихся ЛЛМ) → инструкция → пример → 12 ситуаций выбора
(10 уникальных + 2 повтора) → благодарность.

В каждой ситуации три гипотетических сервиса (А, Б, В), шесть
характеристик, уровни — бренды («как у GigaChat», «как у ChatGPT»…), BDCE.

| файл | назначение |
|---|---|
| `app.py` | маршруты и логика прохождения |
| `admin.py` | подсчёты для панели `/results` |
| `design/attributes.json` | характеристики и уровни-бренды |
| `design/questions.json` | вопросы анкеты; `"type": "grid"` — таблица «бренд × вариант», `skip_if` — пропуск |
| `design/generator.py` | план заданий: в строке бренды всегда разные, каждый бренд показывается одинаковое число раз |

## Запуск локально

```sh
cd students
docker compose up --build
```

Открыть http://localhost:8001/students. Панель: http://localhost:8001/students/results
(ключ — `RESULTS_KEY` из `students/.env`, локально `test`).

## Данные

База — `students/data/survey.sqlite3`, отдельная от опроса врачей.
Кука сессии своя (`students_session`, путь `/students`), с опросом врачей
не конфликтует.

CSV: строка на ситуацию. `A_*`, `B_*`, `C_*` — бренды профилей;
`order` — какие профили стояли в колонках слева направо (например `BCA`);
`choice` — выбранный профиль; `choice_position` — колонка на экране (1/2/3);
`repeat_consistent` = 1, если в повторе выбран тот же профиль.
Ответы таблицы брендов — колонки `brand_gigachat`, `brand_alice` и т.д.

Резервная копия базы на работающем сервере:

```sh
docker compose exec web python -c "import sqlite3; s=sqlite3.connect('/data/survey.sqlite3'); d=sqlite3.connect('/data/backup.sqlite3'); s.backup(d); d.close()"
```

Шрифты Manrope и Unbounded лежат в `static/fonts` (лицензия OFL).
